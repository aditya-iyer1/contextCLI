# Plan 02-01: Run provenance columns, migration, internal run registration

## Objective

Satisfy **STA-01**: `state.db` records **run-level provenance** (`internal` vs future `imported`) with **backward-compatible migration**, and **`Runner`** registers **internal** runs at execution start. **No** `predictions` columns for `failure_type` or provenance; **no** import CLI (Phase 3).

## Task 1 — Idempotent `runs` schema (`state.py`)

<action>
In **`StateManager._init_db`** (or a dedicated **`_migrate`** called from `_init_db` before `commit`):

1. After `CREATE TABLE IF NOT EXISTS runs (...)` (existing definition), **idempotently** add columns if missing (use `PRAGMA table_info(runs)` and conditional `ALTER TABLE`, or `try/except sqlite3.OperationalError` per `ALTER`):

   - `run_source TEXT NOT NULL DEFAULT 'internal'`
   - `external_label TEXT NULL`
   - `artifact_ref TEXT NULL`

2. **Do not** change **`predictions`** table definition in this phase (no `failure_type` column).

3. **Backfill** after columns exist:
   - `UPDATE runs SET run_source = 'internal' WHERE run_source IS NULL OR trim(run_source) = ''` (safety).
   - For every **`run_id`** appearing in **`predictions`** but **not** in **`runs`**, **`INSERT`** a row:
     - `run_id` = distinct value from `predictions`
     - `timestamp` = `CURRENT_TIMESTAMP` (or SQLite `datetime('now')`)
     - `config` = `NULL` unless you have a convention (prefer `NULL` for legacy).
     - `run_source` = `'internal'`
     - `external_label` = `NULL`, `artifact_ref` = `NULL`

   Use a single SQL statement with `INSERT OR IGNORE` + `SELECT DISTINCT run_id FROM predictions WHERE run_id NOT IN (SELECT run_id FROM runs)` or equivalent.

4. Keep **`conn.commit()`** / close pattern consistent with existing code.
</action>
