# Plan 03-01: Import bridge — JSON artifact, CLI, SQLite writes, minimal report line

## Objective

Implement **IMP-01**: **`contextcliff import`** reads a **single versioned JSON** file, validates **`schema_version`**, writes **`runs`** (`run_source='imported'`, `external_label`, `artifact_ref`, `config` from `run_metadata`) and **`predictions`** rows, enforces **collision rules** vs **internal** runs, supports **`--replace`** for **imported** only, and adds a **one-line provenance prefix** to **`CliffProfiler`** markdown output when **`run_source`** / **`external_label`** are present.

## Requirements addressed

| ID | Coverage |
|----|----------|
| **IMP-01** | CLI import, SQLite persistence, retrievable imported labeling, reporting path unchanged aside from minimal header |

## Strategy

One wave. New module for parse/validate; **`StateManager`** gains import-safe DB helpers; **`cli/main.py`** registers **`import`**; **`cliff.py`** accepts optional provenance; **`docs/architecture.md`** short import bullet (no `.planning/` links).

## Task 2 — `StateManager`: provenance read + imported write path

<action>

1. **`get_run_provenance(self, run_id: str) -> Optional[Dict[str, Any]]`**  
   Return `None` if no `runs` row; else `run_id`, `run_source`, `external_label`, `artifact_ref`, `config` (as needed for reporting).

2. **`import_external_run(...)`** (name flexible) performing in a **single transaction**:
   - Args: `run_id`, `label`, `artifact_ref` (optional), `config_json: str` (from `run_metadata`), `prediction_rows: List[Tuple/...]` matching `INSERT INTO predictions` columns.
   - **Insert/update `runs`:** `run_source='imported'`, `external_label=label`, `artifact_ref=artifact_ref`, `timestamp=CURRENT_TIMESTAMP`, `config=config_json`.

3. **Collision logic (D-04–D-05):**
   - If **`runs`** row exists and **`run_source='internal'`** → raise **`ValueError`** (or custom exception) — **no** `--replace` escape.
   - If row exists and **`run_source='imported'`** and **`replace=False`** → raise **`ValueError`** (“use --replace”).
   - If row exists and **`run_source='imported'`** and **`replace=True`** → `DELETE FROM predictions WHERE run_id=?` then insert new prediction rows; **UPDATE** `runs` SET fields above.

4. If **no row** → **INSERT** `runs` then **INSERT** all predictions (batch or loop with existing `save_prediction` pattern — **Claude’s discretion**; must match **`predictions`** schema exactly).

5. **Do not** call **`register_internal_run`** for this path.

</action>
