# Plan 07-01: Controlled synthetic dataset (`alpha_synthetic`) — SIG-02

## Objective

Implement **SIG-02**: a **single** seedable **extractive-QA** synthetic corpus, CLI slug **`alpha_synthetic`**, **designed bins** (not quantiles), **needle-offset** as the primary difficulty knob, **monotonic** context length in **k**, **equal `n` per bin**, wired through **`contextcliff prepare --dataset alpha_synthetic`** with **no new CLI commands**. Fill **Implementation summary** in [`.planning/DATASET-SIG02.md`](../../DATASET-SIG02.md).

**must_haves (goal-backward):**

1. `uv run contextcliff prepare --dataset alpha_synthetic --bins K` writes **`manifest.json`** deterministically for fixed **K** and code version.
2. Every `Example` has **non-empty** `answers`, answer substring **present** in `context`, and **`metadata`** includes **`synthetic_version`**, **`alpha_bin`** (1…K), **`needle_offset`** (character index of answer start in `context`).
3. For fixed seed: **`context_tokens`** strictly **increases** with **`alpha_bin`** (monotonic length by construction).
4. [`.planning/DATASET-SIG02.md`](../../DATASET-SIG02.md) **Implementation summary** section lists: seed constant **name**, **K**, **n per bin**, **tokenizer encoding id** (`o200k_base` / fallback).

**Out of scope:** `run` / API (**Phase 8**), golden JSONL, new CLI flags beyond existing `prepare` options.

---

## Strategy

One wave: **generator** (needle-offset + filler) → **adapter** (`BaseAdapter`) → **sampler dispatch** + **`prepare` wiring** → **tests** → **DATASET-SIG02** summary.

**NarrativeQA behavior:** Keep current semantics: `prepare --dataset narrativeqa --bins X` passes **`X` as `n_per_bin`** to the quantile path (existing code path); internal quantile bin count stays **10** as today. **`alpha_synthetic`** interprets **`--bins` as `K`** (designed strata count).

## Task 1 — Generator: `src/contextcliff/data/alpha_synthetic_generator.py`

<action>

Create a new module **`src/contextcliff/data/alpha_synthetic_generator.py`** that defines:

1. **Constants** (exact names for acceptance):
   - **`ALPHA_SIG02_SEED`** = `42` (integer; document in module docstring).
   - **`SYNTHETIC_VERSION`** = `"sig02-v1"` (string; must match [`.planning/DATASET-SIG02.md`](../../DATASET-SIG02.md)).
   - **`N_PER_BIN_DEFAULT`** = `10` (integer; examples per designed bin when caller does not override).

2. **Function** **`build_alpha_synthetic_examples(n_bins: int, n_per_bin: int, seed: int) -> list[Example]`** that:
   - Imports **`Example`** from **`contextcliff.data.formats`**.
   - Uses **tiktoken** encoding **`o200k_base`** with **`cl100k_base`** fallback (same try/except pattern as [`NarrativeQAAdapter`](../../../src/contextcliff/data/adapters/narrative_qa.py) lines 19–28).
   - For each **`bin_index`** in **`1 .. n_bins`** (inclusive) and each **`j`** in **`0 .. n_per_bin-1`**:
     - Builds a **unique answer string** (ASCII), e.g. **`f"asig02_{bin_index:02d}_{j:02d}_answer"`** (must be unique per example).
     - Builds **`context`** as: a **prefix filler** (repeat a fixed token-like substring e.g. `" …pad… "` or `" lorem "` blocks) whose **length grows with `bin_index`**, then a **needle line** that contains the answer verbatim as a **contiguous substring**, then optional **suffix filler** if needed so total length is monotonic in **`bin_index`** (prefix growth is the primary driver).
     - Sets **`question`** to a single extractive instruction, e.g. **`"What is the exact answer string between the markers <<< and >>> ?"`** and wrap the answer in **`<<<`** and **`>>>`** in the needle line so the model task is unambiguous (or equivalent: answer must be **verbatim** substring of context).
     - **`needle_offset`** = **`.find(answer)`** on **`context`** (must be **≥ 0**); if not found, raise **`RuntimeError`** (fail fast).
     - **`context_tokens`** = **`len(enc.encode(context))`** using **`enc`** above.
     - **`id`** = **`f"alpha_sig02_{bin_index:02d}_{j:03d}"`**.
     - **`metadata`** = **`{"synthetic_version": SYNTHETIC_VERSION, "alpha_bin": bin_index, "needle_offset": needle_offset}`** ( **`alpha_bin`** integer **1…n_bins**).
   - **Monotonicity:** After building all examples, **assert** for each pair **`bin_index < bin_index'`** that **any** example in **`bin_index`** has **`context_tokens` <** any example in **`bin_index'`** OR implement construction so **min tokens(bin) < min tokens(bin+1)** — acceptance uses **min per bin** comparison in tests.

3. **Docstring** on the module: 4–8 lines stating **needle-offset** primary, filler secondary, aligned with [`.planning/DATASET-SIG02.md`](../../DATASET-SIG02.md).

</action>
