# Plan 04-01: Analysis & reporting — filters, caveats, positional diagnostics, latency wording

## Objective

Implement **ANA-01–ANA-04** by extending the **`profile`** command and the **`ResultBinner` → `CliffProfiler`** pipeline: optional **row filters** driven by **`runs.config["analysis_filters"]`** with **CLI overrides**, optional **`--manifest`** join for per-example metadata, **markdown caveats** for imported/external method runs, **positional diagnostics** when manifest metadata includes a documented bucket key, and explicit **metrics interpretation** separating **per-request `latency_ms`** from **throughput** (never infer throughput from mean latency).

## Requirements addressed

| ID | Coverage |
|----|----------|
| **ANA-01** | Optional `analysis_filters` + CLI token bounds; compression-active filter when manifest provides `metadata`; warning in report if filter requested but not applicable |
| **ANA-02** | `## Caveats` section + provenance header includes `artifact_ref` when set |
| **ANA-03** | `## Positional diagnostics` when `--manifest` present and `metadata["needle_position_bucket"]` (str) exists for joinable rows |
| **ANA-04** | `## Metrics interpretation` bullets: latency = per-request; throughput not derived from latency; optional config note for batch/total wall clock |

## Strategy

Single wave. New helper module holds **config parsing**, **manifest load/join**, **row filtering**, and **markdown fragments**. **`CliffProfiler.generate_markdown_report`** gains a single optional structured extra (dataclass or `TypedDict`) so **`profile`** stays thin. **No** SQLite schema migration unless a task proves manifest join insufficient (not expected).

## Task 1 — `src/contextcliff/analysis/profile_report.py` (filters, manifest join, markdown helpers)

<action>

1. Add **`src/contextcliff/analysis/profile_report.py`** with **documented constants** at module top:

   - **`ANALYSIS_FILTERS_KEY`** = `"analysis_filters"` (object inside parsed `runs.config` JSON).
   - Sub-keys: **`min_prompt_tokens`** (`int` \| omit), **`max_prompt_tokens`** (`int` \| omit), **`compression_active_only`** (`bool`, default `False` when absent).
   - **Manifest join key:** predictions use **`example_id`**; manifest JSON entries use **`id`** (from `dataclasses.asdict(Example)`). Join on **`df["example_id"] == manifest["id"]`**.
   - **Compression metadata key:** **`compression_active`** inside each manifest row’s **`metadata`** dict (bool). When **`compression_active_only`** is true: keep rows where joined `metadata.get("compression_active") is True`; drop rows with `False` or missing after join; rows with no manifest match when manifest is present → **exclude** from filtered set (or document as dropped — prefer **exclude** to avoid counting unmatched as “non-compressed”).
   - **Positional metadata key:** **`needle_position_bucket`** (`str`) in **`metadata`**. Group by this column (non-null only), compute **mean F1** and **count** per bucket; emit a markdown table string for **`## Positional diagnostics`**. If **`compression_active_only`** produced a warning, positional may still run on **filtered** `df`.

2. **Functions (names flexible but must exist and be testable):**

   - **`parse_run_config(config_str: Optional[str]) -> dict`** — `json.loads` empty/missing → `{}`; catch `JSONDecodeError` → `{}` or re-raise per caller (profile should not crash profile; log warning in report if config invalid — **prefer:** return `{}` and add warning line `"runs.config is not valid JSON; analysis_filters ignored"`).

   - **`effective_filters(run_config: dict, cli_min: Optional[int], cli_max: Optional[int]) -> dict`** — merge **`run_config.get("analysis_filters", {})`** with CLI: **`cli_min` / `cli_max` override** keys **`min_prompt_tokens` / `max_prompt_tokens`** when not `None`.

   - **`load_manifest_df(path: str) -> pd.DataFrame`** — read JSON array; normalize to columns at least **`id`**, **`metadata`** (dict); `pandas.json_normalize` optional for inner keys.

   - **`apply_prediction_filters(df: pd.DataFrame, filters: dict, manifest_df: Optional[pd.DataFrame]) -> tuple[pd.DataFrame, list[str]]`** — returns filtered frame and **warning strings** (e.g. `"compression_active_only requested but --manifest not provided; filter skipped"`). Apply **min/max prompt_tokens** first on `df["prompt_tokens"]`. Then compression filter if requested and manifest joined.

   - **`build_positional_section(df: pd.DataFrame, manifest_df: Optional[pd.DataFrame]) -> Optional[str]`** — return `None` if manifest missing or no **`needle_position_bucket`** in joined metadata; else markdown table.

   - **`build_caveats_section(provenance: dict, run_config: dict) -> Optional[str]`** — return `None` only if **no** caveat triggers; triggers include: **`run_source == "imported"`**, **`artifact_ref` truthy**, or **`run_config`** has any of keys **`method`**, **`compression_method`**, **`model`**, **`analysis_filters`**. Imported runs must include **at least one** bullet stating metrics reflect **external** execution, not in-repo API timing semantics. **D-05:** Include a bullet that **F1/EM are comparable only as scoring metrics**, not as proof of identical experimental conditions between internal and imported runs; **no** language implying full numerical equivalence of experiments across sources.

   - **`build_metrics_interpretation_note(provenance: dict, run_config: dict) -> str`** — fixed bullets for **latency_ms** = per-request wall time; **do not** equate mean latency to throughput. If **`run_config`** contains **`batch_size`** and **`total_wall_clock_s`** (both numbers), add optional line: *"External run metadata: batch_size={…}, total_wall_clock_s={…} (throughput may be derived as N/total only if N is the full evaluated count)."* — exact wording **Claude’s discretion** but must not claim throughput without user-provided totals.

3. **Unit tests** must cover: token min/max, compression warning without manifest, positional table when bucket present, caveat line for imported.

</action>
